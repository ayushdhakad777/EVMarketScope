EVMarketScope website

Open index.html through a local web server (for example VS Code Live Server) or deploy the contents of this folder to GitHub Pages.
The dashboard loads the supplied 100,000-row CSV in the browser and all three filters update the charts.
The site uses the supplied Craftivo asset bundle and a custom EVMarketScope layout inspired by the reference website.
Internet access is required for Google Fonts, Chart.js and PapaParse CDNs.
